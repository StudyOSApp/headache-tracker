# Headache Tracker

An experimental, privacy-conscious headache and migraine tracking web app.

## Phase 1

This repository currently contains only the mobile application shell and GitHub Pages deployment workflow. It does not store health information, connect to external services, or include tracking analytics.

## Development

Open `index.html` in a browser, or serve this directory with any static file server.

## Deployment

Pushes to `main` deploy to GitHub Pages via the included GitHub Actions workflow. In the repository settings, set **Pages** to use **GitHub Actions** as its build and deployment source.

## Planned next steps

Phase 2 will add the first headache logging experience. No data model or health-related logging functionality is implemented yet.
